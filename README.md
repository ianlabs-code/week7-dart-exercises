## Scenario
This console program calculates the cost of buying notebooks, applies a 10% student discount, checks whether the final total fits a PHP 150.00 budget, and demonstrates integer division and remainder.

## Dart concepts demonstrated
- Explicitly typed variables: `String`, `int`, `double`, and `bool`
- Arithmetic operators: `*`, `-`, `/`, `~/`, `%`, and `++`
- Comparison operator: `<=`
- Readable console output using `print()` and string interpolation

## Requirements
Install the Dart SDK, or install Flutter (which includes Dart), and install the Dart extension in Visual Studio Code.

## How to run
Open this project folder in VS Code. In the integrated terminal, run:

```bash
dart --version
dart format .
dart run
```

The expected console output is saved in [`output.txt`](output.txt).
